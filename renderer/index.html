Optional engines

The core edition uses a separate engine pack for media, English scan recognition, PDF rendering and PSD images. Common image conversions work without it. Import the pack supplied with this build. Checksums must match before anything is installed.

Built in, every time

Originals stay safe Always on

Outputs use your folder and naming defaults. Replace sends the previous output to the Recycle Bin. Selected originals are never overwritten. A failed conversion cleans up its incomplete outputs.

Work with a selection Always on

Browse for several files, drop into the app or use Explorer. Mixed selections show common supported destinations. Up to three files convert concurrently, and a failed file does not stop the others.

Find and reuse your work Included

Search recorded conversions, filter images, video, audio or documents, open an output, reveal its folder or convert its source again.

Progress and recovery Always on

The palette shows conversion progress, success and errors. Escape dismisses a selection. Releasing Ctrl lets an Explorer drag continue normally.

Local processing Always on

Conversion engines run on your PC. Document rendering can load resources referenced by HTML or e-mail, such as linked images.
